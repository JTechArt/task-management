## Add-on . Plugin management
We have a lot of features epic 7,8,9,10 that can be implemented as a separate feature / plugin and apply if needed. 

For doing that we should adapt application to be plugin attachable. 
In case if plugin attached we need to configure it and start using. 

For example. to be able to use geppa or ai related features we need to configure it. in case if we've not installed some required app these plugins will not work. 

In the future we will have other pluggabl features as well so let's make application pluggable
