Preflight belongs close to task launch. Setup happens in project configuration, but failures must render inline during launch with clear remediation.

Blocking

Java runtime mismatch

`payments-api` requires Java 21, but the detected runtime is Java 17. IDE launch remains disabled until the project profile passes or the repository is removed from this launch.

Suggested fix

Switch `JAVA_HOME` to the configured JDK 21 installation and rerun validation.

Primary
Fallback

Launch without `payments-api` if the task only targets the front-end repository.
